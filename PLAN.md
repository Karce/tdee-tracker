# tdee-tracker — Implementation Plan

> For Claude Code: implement task-by-task on `main`, commit after each task, run `cargo test` before finishing.
> Owner: Karce (master). Operator: Thoth (logs entries from Discord, reads status, drives reminders).

**Goal:** A small Rust CLI (`tdee`) that records daily weight + daily calorie total and computes master's *adaptive* TDEE from the observed weight trend — the r/loseit "adaptive TDEE spreadsheet" method — then tells him what to eat to hit a configured loss rate until a configured goal weight.

**Architecture:** Single binary, `clap` subcommands, one **age-encrypted** JSON data file (config + entries together, exactly the `net-worth-tracker` pattern). Pure functions for the math (unit-tested). `--json` flag on every read command so Thoth/cron can consume output without parsing prose.

**Tech stack:** Rust 2021 (rustc 1.94.1), `clap` 4 (derive), `serde`/`serde_json`, `chrono`, `anyhow`, `dirs`, `age` 0.10 (x25519 recipient). Dev deps: `tempfile`, `secrecy`. No async, no DB.

## 1. Data model

Single encrypted document `data/tdee.json.age` (plaintext shape):
```json
{
  "config": {
    "start_date": "2026-09-02",
    "start_weight_lb": 200.0,
    "goal_weight_lb": 180.0,
    "rate_lb_per_week": 1.0,
    "height_cm": 180.0,
    "age_years": 35,
    "sex": "male",
    "seed_tdee_kcal": 2328,
    "ema_alpha": 0.1,
    "window_days": 28
  },
  "entries": [
    {"date":"2026-09-02","weight_lb":199.6,"kcal":1900,"note":null}
  ]
}
```
Entries: one object per calendar day, **upsert by date**, kept sorted. Either field may be null (weigh-in logged in the morning, kcal at night). `height_cm`/`age_years`/`sex` are stored for the Mifflin-St Jeor seed (`init` computes `seed_tdee_kcal` from them × 1.25 activity factor when `--seed-tdee` is not given; `--seed-tdee` overrides).

## 2. Math (pure functions in `src/calc.rs`, all unit-tested)

1. **Trend weight** — Hacker's Diet exponentially-smoothed moving average over days that have a weight, in date order: `trend[0] = w[0]; trend[i] = trend[i-1] + alpha * (w[i] - trend[i-1])`, `alpha = 0.1`. Days without a weight carry the previous trend value forward (not interpolated).
2. **Adaptive TDEE** over the trailing `window_days` (default 28, capped to data available):
   `tdee = mean(kcal over days with kcal) - (trend_end - trend_start) * 3500 / span_days`
   where `span_days` = calendar days between first and last entry in the window (min 1). Losing weight makes the second term positive, i.e. TDEE > intake. **Return `None` if fewer than 7 days have both weight and kcal.**
3. **Confidence label:** `<7` days → `insufficient`; `7–13` → `rough`; `14–20` → `provisional`; `≥21` → `stable`.
4. **Effective TDEE** used for targets: adaptive if available, else `seed_tdee_kcal` if set, else `None` (status says "log 7 days first").
5. **Target intake** = `effective_tdee - rate_lb_per_week * 3500 / 7` (1 lb/wk → −500).
6. **Observed rate** (lb/week) = `(trend_end - trend_start) / span_days * 7` (negative = losing).
7. **ETA to goal** = `(trend_now - goal) / |observed_rate|` weeks, only when observed rate is negative and confidence ≥ `rough`; also show the *planned* ETA at the configured rate.

**Fixture for tests:** 28 consecutive days, kcal = 2000 every day, weights descending linearly 200.0 → 198.0 (−2 lb over 27 days). Expected: trend_end − trend_start ≈ −1.44 (EMA lag; assert within ±0.05 of the EMA computed by hand in the test), `tdee ≈ 2000 + 1.44*3500/27 ≈ 2187` (assert ±15), confidence `stable`, target ≈ 1687 (±15). Add a second fixture with a gap (missing kcal on 3 days) proving mean ignores nulls and span uses calendar days.

## 3. CLI surface (`src/main.rs` + `src/cli.rs`)

```
tdee init  --start-weight 200 --goal 180 --height-cm 180 --age 35 --sex male [--rate 1.0] [--seed-tdee N] [--start-date YYYY-MM-DD]
tdee log   [--date YYYY-MM-DD] [--weight 199.6] [--kcal 1900] [--note "..."]   # upsert; at least one of weight/kcal required
tdee status [--json] [--brief]
tdee history [--days 30] [--json]
tdee config [--goal 180] [--rate 1.0] [--seed-tdee N] [--window 28]           # no args = print
```

`status` human output (example):
```
2026-09-23  weight 196.4 lb  trend 196.9 lb  kcal 1850 logged
TDEE 2,190 kcal (stable, 21/21 days)  ·  target 1,690 kcal/day for -1.0 lb/wk
observed -0.9 lb/wk  ·  16.9 lb to 180  ·  ETA ~19 wk (Feb 2027)
```
`--brief` → the one line the reminders embed: `trend 196.9 · TDEE 2190 (stable) · eat ≤1690 · -0.9 lb/wk · 16.9 to go`.
`--json` → `{date, weight_lb, trend_lb, kcal, tdee, confidence, days_with_both, target_kcal, observed_rate, lb_to_goal, eta_weeks}`.

Exit codes: 0 ok, 1 user error (bad date, no init), 2 IO/corrupt data (print which line).
